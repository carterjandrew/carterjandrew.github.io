# A Practical Guide to Self Hosting

![booklore-website](/booklore/booklore-home.png)

**Goal**  
Give a simple guide on how you can turn a old laptop into a server you can install and experiment with from anywhere.  
While using best practices in software development.  
For free.

**Cost to start**  
0 dollars  
2 hours

**Tools used**
NixOS, Tailscale
